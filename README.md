# 👥 Kin-Keeper - Relationship & Contact Management Platform

Kin-Keeper is an intuitive web application designed to help users maintain and nurture relationships with their loved ones, friends, and colleagues. It enables efficient conversation tracking, connection logging, and streamlined communication management.

---

## 🎯 Project Objective
The primary goal of Kin-Keeper is to facilitate everyday communication and connection management. Instead of losing track of significant connections, the platform provides an organized interface to log interactions and prioritize meaningful relationships.

---

## ✨ Key Features
* **Contact & Relationship Categorization:** Add, view, and manage contacts categorized by relationships (e.g., Close Friends, Family, Co-workers).
* **Quick Communication Actions:** Integrated action triggers for initiating calls, messages, or video chats.
* **Dynamic Sorting & Filtering:** Advanced options to filter and sort your contact list dynamically based on interaction states.
* **Data Visualization:** Integrated charts to track connection analytics and frequency of communications.
* **Fluid Responsive UI:** Fully optimized layout using Tailwind CSS and DaisyUI that works seamlessly across mobile, tablet, and desktop viewports.

---

## 🛠️ Technologies & Packages Used
* **Core Framework:** React.js (JavaScript ES6+)
* **Styling Engine:** Tailwind CSS & DaisyUI
* **State Management:** React Context API
* **Routing:** React Router DOM
* **Data Visualization:** React Charts
* **Utilities:** React Icons, React Spinners, React Toastify
* **Data Layer:** Local JSON Mock Data
